# Notebooks

This directory holds exploratory and analysis notebooks for the RAG complaint chatbot.

## Suggested notebooks

- `01_eda.ipynb` — Exploratory data analysis of the consumer complaints dataset.
- `02_preprocessing.ipynb` — Cleaning and filtering of complaint narratives.
- `03_chunking_embedding.ipynb` — Chunking experiments and vector store creation.
- `04_rag_evaluation.ipynb` — Qualitative evaluation of the RAG pipeline.

> Keep heavy logic in `src/` modules and import it into notebooks so the code stays testable.
